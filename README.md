# Arc — Claude Architect Prep

An independent, responsive study application for the **Claude Certified Architect — Foundations** exam. It includes the weighted syllabus, concise revision notes, 52 original scenario questions, a 30-question mock exam, explanations, search/filter tools, and local progress tracking.

This project is not affiliated with or endorsed by Anthropic. The practice questions are original and are not real exam items.

## Run locally

```bash
npm install
npm run dev
```

## Validate

```bash
npm test
npm run build
```

The application stores study progress in the browser's `localStorage`; it needs no backend, API keys, or environment variables.

## Content sources

The app links to Anthropic's certification page, Claude documentation, Claude Code documentation, *Building effective agents*, the MCP specification, and the Anthropic Cookbook. Exam logistics can change, so verify scheduling, pricing, question count, and scoring with Anthropic before booking.
